# Pet Vida

A responsive, multi-page website for a fictional pet-care brand — built as a
front-end project with plain HTML, CSS and JavaScript (no frameworks).

**Live demo:** https://joaoferrari12.github.io/petvida-website/

## Pages

Home, About, Cats, Dogs, Services, Partners — a seven-page static site with a
shared layout, navigation and responsive design for desktop and mobile.

## Tech

- **HTML5** and **CSS3** (custom responsive layout, no CSS framework)
- **Vanilla JavaScript**
- **SVG** icons for crisp, lightweight UI graphics
- **WebP** images

## Performance

The original photos shipped at ~18 MB. All 37 raster images were converted to
**WebP** and resized for web display, bringing the full site under **2 MB** — a
~89% reduction — with no visible quality loss at display size.

## Running locally

It's a static site — open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```

then visit http://localhost:8000
